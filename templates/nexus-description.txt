[size=5][b]Installation[/b][/size]

Install [url=https://inidar1.github.io/terraria-modder/installation/]TerrariaModder[/url].

[size=4][b]With [url=https://www.nexusmods.com/terraria/mods/159]TerrariaModder Vault[/url][/b][/size]
You can find the mod in the "Browse Nexus" tab.

[size=4][b]Manually[/b][/size]
[list=1]
[*]Download the latest version of the mod from the [url={files_url}]files tab[/url] or from [url=https://github.com/neverify/terraria-mods/releases]GitHub[/url].[/*]
[*]Extract the downloaded .zip file and move the folder inside into Terraria/TerrariaModder/mods/.[/*]
[/list]
